About
simple mod manager for xxmi supported games that doesn't use electron? how daring!

i'll be honest, i made this mod manager back in the beginning of 2026, not knowing there were existing mod managers... how typical of me.
and i dunno what special features it has that others don't, in fact it lacks some of them (like exporting and stuff), but hey, maybe one day they'll appear in mine too!

it was written in golang (uh-huh, again...) with wails.
How To Use
just like lzhash, it's quite easy to use, but obviously some things might not be as obvious as it is for me, since i made it personal first, and only then decided to make it kinda public-ish?

you can either import from a gamebanana url, or import it manually!

to make it easier to import mods from gamebanana, i also made a helper script for browsers, which adds quick import buttons to supported mods.
Installing
just make sure you have xxmi launcher already installed, you can find it here.
0. locate your xxmi root (click the three dots button near the start button, press "Open Mods Folder", go two folders up until you see "XXMI Launcher Config.json", that's where your xxmi root is)
1. drop downloaded xxmimm in the root folder, and launch it once so it registers the url schema (you can confirm that by opening this, if you see a message then it was registered).
2. start importing mods, either manually by filling up fields, by pasting a gamebanana url in "Auto Import", or by using an userscript.
3. to add a userscript, first make sure your browser has a supported add-on installed (for example, Tampermonkey), then press here to install it.
